
# 🤖 GenAI Web Application

An AI-powered web application that provides smart, fast, and interactive AI experiences using Generative AI technology.

## ✨ Features

- 🤖 AI-powered responses
- 💬 Interactive chat interface
- ⚡ Fast response generation
- 🎨 Modern and attractive UI
- 📱 Fully responsive design
- 🚀 Easy to use

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript
- Generative AI API

## 🚀 Getting Started

### Clone the Repository

```bash
git clone YOUR_REPOSITORY_URL
```

### Navigate to Project Folder

```bash
cd your-project-name
```

### Install Dependencies

```bash
npm install
```

### Run the Project

```bash
npm run dev
```

## 🔑 Environment Variables

Create a `.env` file and add your API key:

```env
API_KEY=your_api_key_here
```

**Note:** Never expose your API key publicly or upload your `.env` file to GitHub.
